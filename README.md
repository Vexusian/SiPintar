# SiPintar — Sistem Terpusat Informasi & Navigasi Terpadu Akademik Responsif

## Deskripsi
Aplikasi untuk mendukung pengelolaan informasi akademik.

## Teknologi
- PHP
- MySQL/MariaDB
- HTML, CSS, dan Bootstrap

## Struktur Dokumentasi
- docs/SDD: dokumen desain perangkat lunak
- docs/STD: dokumen pengujian perangkat lunak

## Persiapan
1. Clone repository.
2. Siapkan web server dan database lokal.
3. Buat database sesuai skrip di folder database.
4. Sesuaikan konfigurasi database lokal.

## Catatan
Petunjuk instalasi dan penggunaan akan diperbarui
sesuai perkembangan proyek.
